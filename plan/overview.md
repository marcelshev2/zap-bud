# Project Overview

## What is Zap-Bud?

Zap-Bud is a personal WhatsApp assistant that runs alongside your conversations. It acts as a smart co-pilot: transcribing voice messages automatically, suggesting context-aware replies, and helping you stay on top of personal productivity (reminders, notes, tasks) — all through WhatsApp itself, with no extra app to open.

## Goals

- **Audio transcription**: Automatically transcribe any voice message received so the user can read it instead of listening.
- **Answer suggestions**: When a message arrives, generate 2–3 smart reply options enriched with relevant context (prior conversation, notes, user preferences).
- **Personal productivity**: Let the user create reminders, capture notes, and manage tasks entirely through natural-language WhatsApp messages.

## Non-goals (v1)

- Group moderation or broadcast features.
- Multi-user / multi-tenant support (single user to start).
- Custom business workflows or CRM integrations.
- Replacing WhatsApp's native interface — the bot complements it, not replaces it.

## Who is it for?

A single user (the owner of the phone number) who wants an AI-powered layer on top of their WhatsApp, reducing friction for productivity tasks and making incoming voice messages instantly readable.
